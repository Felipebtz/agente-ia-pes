# agente-ia-pes
creating a personal agent so you don’t have to rely on tokens or connections/updates from big techs

# Description
Para se criar esse agente pessoal, uma das principais bibliotecas que estamos utilizando para criacao dele de maneira inteligente é  openclaw, que é uma biblioteca que funciona como um recepcionista de um escritorio.

1. Recebe  a mensagem 
2. Entende o que está sendo solicitado
3. Redireciona para o departamento correto (Ollama, ou etc..)
4.coleta resposta
5.Envia uma resposta ao convidado 

entre alguns quesisto de eu usar o openclaw nesse projeto é a chamada de servicos externo e a possibilidade de criacao de RAG ( nossa principal arma)

entre outras como plugin e agendamentos.
